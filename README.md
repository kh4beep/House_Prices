# Проект по задаче "House Prices"

## Инструкция по запуску:

Версия Python: **3.14.6**.

Все команды выполнять из корня проекта: пути в конфиге относительные.

1. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Указать пути к Kaggle `train.csv` и `test.csv` в `config.paths.dataset` и `config.paths.test_dataset` в `config.py`.
3. Для обучения установить `config.general.is_train = True` и запустить:

   ```bash
   python main.py
   ```

4. Для создания submission установить `config.general.is_train = False` и повторно выполнить `python main.py`. Предварительно модели должны быть обучены с `is_save_models = True`; `experiment_name` и состав `to_stacking` должны соответствовать сохранённому обучению.

## Схема оценки

- 20% размеченных данных выделяется в holdout; остальные 80% составляют development-часть. Разделение стратифицировано по бинам `log1p(SalePrice)`, seed — 42.
- На development-части используются 5 стратифицированных фолдов. Преобразования, требующие обучения, обучаются отдельно на тренировочной части каждого фолда.
- Подбор гиперпараметров выполняется только на development-части. CV и OOF используются для разработки; OOF после подбора на всей development-части не является независимой итоговой оценкой.
- Holdout не участвует в подборе и используется для итоговой проверки.
- Основная метрика — RMSLE; дополнительно считаются R² и SMAPE (%).

## Итоговый ансамбль

Используется стекинг с метамоделью Ridge. Базовые модели итогового ансамбля — ElasticNet, CatBoostRegressor, XGBRegressor и DLM; состав задаётся в `models.to_stacking`.

Метамодель обучается на `log1p` OOF-предсказаний. Её целевая переменная — `log1p(SalePrice)` с предварительным ограничением цены сверху параметром `models.stacking.winsorization_value` (500000). При предсказании сначала усредняются прогнозы фолдовых моделей каждого типа, затем их логарифмы передаются в Ridge. Результат возвращается в доллары через `expm1` и ограничивается снизу нулём.
