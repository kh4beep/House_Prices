# Проект по задаче "Титаник"

## Инструкция по запуску:
1. Установить зависимости из requirements.txt
2. Указать актуальные пути до датасета в config.py (config.general.paths.dataset и test_dataset)
3. Запустить файл main.py

## Результаты:
1stFlrSF - площадь первого этажа.
2ndFlrSF - площадь второго этажа.
3SsnPorch - площадь веранды, предназначенной для использования в течение трёх сезонов года.
Alley - тип покрытия переулка или подъезда к участку с задней стороны.
BedroomAbvGr - количество спален над уровнем земли.
BldgType - тип здания (отдельно стоящий дом, дуплекс, таунхаус и т. д.).
BsmtCond - оценка общего состояния подвала.
BsmtExposure - степень открытости подвала относительно уровня земли.
BsmtFinSF1 - площадь первой отделанной части подвала.
BsmtFinSF2 - площадь второй отделанной части подвала.
BsmtFinType1 - тип отделки и использования первой части подвала.
BsmtFinType2 - тип отделки и использования второй части подвала.
BsmtFullBath - количество полноценных ванных комнат в подвале.
BsmtHalfBath - количество ванных комнат с частичным набором сантехники в подвале.
BsmtQual - оценка высоты и качества подвального помещения.
BsmtUnfSF - площадь неотделанной части подвала.
CentralAir - наличие центральной системы кондиционирования воздуха.
Condition1 - близость дома к важным объектам или неблагоприятным факторам (железная дорога, главная улица и т. д.).
Condition2 - дополнительная характеристика близости дома к таким объектам или факторам.
Electrical - тип электрической системы дома.
EnclosedPorch - площадь закрытой веранды.
ExterCond - оценка состояния внешней отделки дома.
Exterior1st - основной материал внешней отделки дома.
Exterior2nd - дополнительный материал внешней отделки дома.
ExterQual - оценка качества внешней отделки дома.
Fence - качество и тип ограждения участка.
FireplaceQu - оценка качества и состояния камина.
Fireplaces - количество каминов.
Foundation - тип фундамента дома.
FullBath - количество полноценных ванных комнат над уровнем земли.
Functional - оценка функциональности планировки дома и наличия необходимых помещений.
GarageArea - площадь гаража.
GarageCars - вместимость гаража по количеству автомобилей.
GarageCond - оценка текущего состояния гаража.
GarageFinish - степень внутренней отделки гаража.
GarageQual - оценка качества гаража.
GarageType - расположение и тип гаража (пристроенный, встроенный, отдельно стоящий и т. д.).
GarageYrBlt - год постройки гаража.
GrLivArea - общая жилая площадь над уровнем земли (без подвала).
HalfBath - количество ванных комнат с частичным набором сантехники над уровнем земли.
Heating - тип системы отопления дома.
HeatingQC - оценка качества и состояния системы отопления.
HouseStyle - архитектурная планировка дома по этажности и расположению жилых помещений.
KitchenAbvGr - количество кухонь над уровнем земли.
KitchenQual - оценка качества кухни.
LandContour - рельеф участка (ровный, с уклоном, на склоне).
LandSlope - крутизна уклона земельного участка.
LotArea - общая площадь земельного участка.
LotConfig - расположение участка относительно соседних участков и улиц.
LotFrontage - длина границы участка, примыкающей к улице.
LotShape - форма земельного участка (правильная или неправильная).
LowQualFinSF - площадь жилых помещений с низким качеством отделки.
MasVnrArea - площадь декоративной каменной или кирпичной облицовки фасада.
MasVnrType - тип декоративной каменной или кирпичной облицовки фасада.
MiscFeature - наличие дополнительных объектов на участке, не описанных другими признаками (например, сарай, теннисный корт).
MiscVal - денежная стоимость дополнительных объектов на участке.
MoSold - месяц продажи дома.
MSSubClass - тип жилого здания по классификации недвижимости (например, одноэтажный дом, двухэтажный дом, таунхаус).
MSZoning - категория зонирования участка по назначению и допустимому использованию.
Neighborhood - район, в котором расположен дом.
OpenPorchSF - площадь открытой веранды или крыльца.
OverallCond - общая оценка текущего состояния дома.
OverallQual - общая оценка качества материалов и отделки дома.
PavedDrive - тип покрытия подъездной дороги к гаражу.
PoolArea - площадь бассейна.
PoolQC - оценка качества бассейна.
RoofMatl - материал кровельного покрытия.
RoofStyle - конструкция и форма крыши.
SaleCondition - условия и особенности продажи дома.
SalePrice - фактическая цена продажи дома.
SaleType - тип сделки, по которой был продан дом.
ScreenPorch - площадь веранды с москитными сетками.
Street - тип дорожного покрытия улицы, к которой примыкает участок.
TotRmsAbvGrd - общее количество комнат над уровнем земли, без учёта ванных комнат.
TotalBsmtSF - общая площадь подвала.
Utilities - доступность коммунальных услуг (электричество, вода, канализация, газ).
WoodDeckSF - площадь деревянной террасы или настила.
YearBuilt - год первоначальной постройки дома.
YearRemodAdd - год последней реконструкции или существенного обновления дома.
YrSold - год продажи дома.
